# sales-performance-dashboard-excel
# Superstore Sales Excel Dashboard

An interactive **Sales Performance Dashboard** built entirely in Microsoft Excel for the famous Superstore dataset (2014–2017).

<img width="1841" height="953" alt="Dashboard" src="https://github.com/user-attachments/assets/98f7b9e3-bb9f-45de-b445-3730b44f8b68" />


# Features

- Dynamic Dashboard with Slicers (Category, Year, State)
- Sales by Category (Horizontal Bar Chart)
- Profit Trend Over Years (Line Chart)
- Sales by State (Map using Filled Map)
- Monthly Sales Trend
- Top 5 Customers (Pie + Table)
- Customer Count by Year
- Key Performance Indicators (KPIs)

# Tools & Techniques Used

- Pivot Tables
- Pivot Charts
- Slicers & Timeline
- Filled Maps
- Conditional Formatting
- Formulas (SUMIFS, INDEX, MATCH, etc.)
- Dashboard Layout Design

# Key Insights

- **Technology** category has the highest sales and profit.
- **California, New York, and Texas** are the top performing states.
- Profit in Furniture is relatively low compared to sales.
- Steady growth in sales from 2014 to 2017.
- Top customer: **Tamara Chand**


## Business Recommendations
- Focus more on **Phones, Chairs, and Storage** products
- Improve profitability in the **Furniture** category
- Run targeted campaigns in high-potential states
